# 功能落地与连接说明

本轮接通的是站长后台内的实际操作链。NewAPI 仍为独立上游，登录注册探针无需修改
NewAPI 源码；调用出口继续来自 NewAPI 使用日志。没有真实凭据的服务保留待配置状态。

## 已完成的链路

| 模块 | 实际行为 | 页面入口 |
| --- | --- | --- |
| 用户注销与彻删 | 原因必填、管理员保护、幂等键、认证数据清理、持久操作记录与风险审计 | 用户管理 → 操作记录／删除／清理已注销账号 |
| 账号关联 | 成功认证 BrowserID 与共享令牌证据进入个人评估、扫描、AI 输入和可疑队列 | 风控中心与用户风险卡片 |
| 调用异常 | 按历史基线检测失败率、额度突增、模型集中失败，阈值可保存 | 风控中心 → AI 审核 → 规则与 AI |
| 人工复核 | 已核实、误报、待观察及理由保存到原评估、复核历史和审计 | 风控详情 → 复核结论 |
| 连接配置 | DSN／密钥脱敏，数据库类型切换校验、只读连接检查，保存后重启应用 | 系统连接 |
| IP 后台导入 | 每批事件与游标原子提交，后台定时增量导入，显示进度、取消及中断续传 | IP 分析 → 数据质量 |
| IP 聚合与导出 | 筛选条件下流式读取，按窗口、来源和版本缓存，CSV 导出同一窗口全部出口 | IP 分析 → 导出 IP |
| IP 属性修正 | 人工属性与自动识别分开，版本冲突保护、原因和前后快照 | 查询单个 IP → 补录／修正属性 |
| IP 数据维护 | 定时下载、大小及格式校验、版本切换、热加载、失败保留旧版 | IP 分析 → 数据质量 → 数据维护 |
| 独立 IP 数据库 | 上传 ISP／Anonymous-IP MMDB，验证数据库类型后生效 | IP 数据维护 → 导入 |
| 事件保留 | 默认永久保留，配置期限后先预览，填写原因和确认文字才清理 | IP 数据维护 → 事件保留 |
| 圈钱中心 | 继承主后台数据源与认证，订单／补发／日报周报记录真实投递回执 | 圈钱中心 |
| 登录注册探针 | 独立网关、签名上报、磁盘队列、重试、机器认证就绪检查 | 集成启动器／Compose probe profile |

## 检测与处置边界

共享调用出口、代理、机房、同浏览器多账号均为需解释的证据，不单独自动封号。
新增失败率、消耗和模型失败规则只触发复核。自动处置继续要求原有组合规则、
足够的事件样本、包含上一基线窗口的完整调用历史、AI 与执行配置门槛。
人工标记误报后，该评估不能继续作为自动处置依据；后续新证据仍重新评估。

未验证账号的失败登录和待确认注册不建立成功 BrowserID 账号归属。
调用 IP、登录 IP、注册 IP 分源统计；没有代理数据时保持未知。

清理只删除 `siteadmin_network_events` 中明确早于截止时间的事件，不删除 NewAPI
源调用日志、财务记录、用户操作与风控审计。清理会记录覆盖截止时间，影响的历史窗口
不会继续声明完整，“从未调用”和自动处置同样读取该覆盖状态。
后续导入跳过已清理截止时间以前的迟到记录。

## IP 数据维护

默认每 24 小时检查更新，更新周期支持 6～720 小时。下载代理可配置为无账号密码的
HTTP(S) 或 SOCKS5 地址；下载只取共享离线数据库和名单，不上传用户 IP。
识别来源和许可证说明随数据版本保留。

VPN／非住宅名单超过 3 天提示陈旧，超过 14 天停止作为当前命中证据；
Tor 名单超过 1 天提示陈旧，超过 3 天停止使用。更新失败继续保留当前可用版本，
不把未命中解释为“不是代理”。复制原数据到新版本保留文件修改时间，导入额外数据库
不会刷新旧名单的有效期。

独立 ISP、公共代理、住宅代理属性取决于实际导入数据库的内容与覆盖。程序支持接入
不代表已经购买或取得这些数据。ASN 组织名称不自动冒充独立 ISP。

## 保存配置与运行

常规服务启动读取 `DATA_DIR/connections.json`；`SITEADMIN_CONFIG_FILE` 可指定同一配置
文件的明确路径。文件只保存允许的连接项，环境中的后台管理员令牌和机器密钥不通过
该页面修改。已保存项优先于环境配置，重启后应用，运行中不替换数据库连接池。

Windows 演示入口将连接配置保存到项目 `data/connections.json`，但启动时设置
`IGNORE_SAVED_CONNECTIONS=true`，因此演示预览始终使用样本。保存真实配置后，
停止演示进程，再运行 `Start-Integrated.ps1`；集成启动器使用该文件及 `.env`，
并启动真实财务与按配置启用的探针。

管理库连接用于 NewAPI 管理写入和 `siteadmin_*` 状态表，应指向可写的 NewAPI 数据库，
不能把它填成没有 `users`／`tokens` 等表的空白库。留空时使用主库连接。

部署细节见 [集成运行与部署](integrated-deployment.md)。仅“已配置”不代表连接或投递成功：
系统连接页和模块就绪检查显示实际状态；钉钉验证来自当前通知配置对应的真实发送结果。

## 外部激活所需值

- 真实 NewAPI 主库／独立日志库连接。
- NewAPI 上游地址、管理员 ID 和管理员令牌。
- AI 兼容接口地址、API 密钥和模型。
- 钉钉 Webhook 与对应签名密钥。
- 登录控制台及认证入口实际经过探针的反代路由。

本地构建和预览可以在这些值为空时运行。空值不使用演示结果冒充真实接通。
本轮不执行真实用户删除、封禁或通知发送；完整业务测试由使用者随后进行。
