# IP 分析功能与联动分析

更新日期：2026-11-24。本说明对应站长后台当前实现，不代表已接入真实 NewAPI 或完成业务测试。

本轮已安装真实离线 IP 数据：GeoLite2 City／ASN、X4BNet VPN／非住宅网段、Tor 官方出口。
选型、newapitools 源码对比、实际加载条数及更新方式见 [IP 识别选型与部署](ip-provider-selection.md)。

## 功能清单

| 功能 | 当前能力 | 分析与边界 |
| --- | --- | --- |
| 来源隔离 | 调用 IP、登录 IP、注册 IP 三类独立统计 | 调用来自 NewAPI 消费／错误日志；登录与注册来自外置探针，不能互相推断 |
| 时间与条件 | 1／3／6／12／24 小时、3／7／30／90 天；用户、令牌、IP 精确筛选 | 令牌条件只用于调用来源；支持传入固定起止秒数 |
| 统计概览 | 独立 IP、事件、关联账号、成功占比、IP 采集率、GeoIP 库状态 | 成功、失败、待确认分别保留；未记录或非法 IP 不创造出口 |
| 全部出口 | 全量有效出口分页，包含单账号、单出口令牌 | 修复原来只看共享 IP 时，单账号或单出口查询没有结果的问题 |
| 出口关联 | 共享出口、多出口账号、多出口令牌、用户出口明细 | IP 分析的多出口门槛为 2；风控监控关注门槛为 3，页面明确区分 |
| 用户与令牌身份 | 展示名称、当前状态及账号关系，可打开详情卡片 | 资料读取失败保留 ID 与未知状态；关联接口不返回令牌密钥 |
| IP 行为详情 | 同一 IP 的三来源独立汇总、账号／令牌／事件／浏览器分页 | 不将三来源事件合成一个身份结论；令牌筛选下认证来源显示不适用 |
| 网络画像 | 国家、省州、城市、ASN、组织、ISP、网络类型、地址类型 | 地域、ASN、ISP 和代理数据各有独立来源与版本；没有库时保持未知 |
| 代理属性 | VPN、公共代理、住宅代理、Tor 的命中／未命中／未知 | 不把托管网络直接判断为代理，也不把代理判断为违规 |
| 地图与地域排名 | 世界／中国地图；国家、省州、城市排名 | 排名新增分页；账号在地域内去重，跨地域人数不能直接相加 |
| 趋势与分布 | 分源事件趋势、ASN、地址类型、网络类型和代理统计 | 网络类型原有返回值已接入界面；ASN 排名新增分页 |
| 登录浏览器 | IP 详情与风控监控按成功认证且有用户 ID 的 BrowserID 建立关联 | 失败、待确认或未认证的账号填写行为不建立同浏览器账号证据 |
| 数据质量 | IP 采集、账号归属、地域、ASN、代理覆盖率及历史状态 | 覆盖率的分母不同；未观测到探针事件不能解释为没有登录 |
| 刷新与导入 | 手动／自动刷新；调用日志增量导入、幂等游标、排除任务结算 | 仅处理既有日志，缺失的历史 IP 无法恢复；没有改动 NewAPI 项目 |
| 查询还原 | 来源、时间、账号、令牌、IP、关联视图写入 URL | 刷新或通过链接进入可恢复条件；固定窗口可解除后恢复滚动范围 |
| 属性补录 | 可视化编辑、乐观版本保护、修改原因和前后快照 | 人工属性独立保存，不把自动推断值默认写为人工证据 |

## 本轮补齐的操作链

| 起点 | 操作 | 到达位置与保留条件 |
| --- | --- | --- |
| IP 分析全部／共享出口 | 点击 IP 或详情 | 共用 IP 详情弹窗，保留来源、时间和用户／令牌条件 |
| IP 分析多出口账号 | 点击账号区域 | 用户卡片，可查看账号、调用、登录设备、风控和签到 |
| IP 分析多出口令牌 | 点击令牌名称 | 令牌分析弹窗，使用原查询窗口 |
| IP 详情关联账号 | 点击账号区域 | 用户详情卡片；不是跳到全部用户列表 |
| IP 详情账号风控按钮 | 点击盾牌 | 直接打开该账号的风控分析页签；风控分析仍使用风控配置的评估窗口 |
| IP 详情关联令牌 | 点击令牌区域 | 打开令牌分析，关闭返回原 IP、来源、页签和分页 |
| 风控 IP 监控 | 点击共享 IP、常用出口或令牌 | 共用详情与令牌分析，保留监控原始时间窗口 |
| 用户登录与设备 | 点击登录／注册／调用 IP | 共用 IP 详情；未认证尝试不携带被填写账号的用户筛选 |
| 令牌分析 | 点击来源 IP 或请求日志 IP | 共用 IP 详情，来源固定为调用，携带令牌与精确窗口 |
| IP 详情展开分析 | 打开完整 IP 分析页 | URL 携带 IP、来源、起止时间和有效条件 |

主要代码为 `frontend/src/IPDetailsContext.tsx`、`IPDetails.tsx`。
用户、风控、令牌和 IP 分析共用这一个入口，不分别维护四种 IP 详情。

## 统计口径

### 调用出口

调用采集使用日志类型 `2`、`5`，排除可识别的任务结算记录。记录 ID 用于增量幂等导入，
不是用请求 ID 合并渠道重试。IP 规范化使用同一实现，IPv4 映射 IPv6 合并为 IPv4。
缺失和无效 IP 不计入出口数量；公网与有效非公网地址分开分类。

本轮令牌列表出口数、疑似泄漏出口数、令牌分析的独立 IP 和出口排行，改用相同的采集事件口径。
出口排行最多列出 20 个，独立出口数保留全量计算。同步失败或源日志没有 IP 字段时返回未知，
令牌分析的 `unique_ips` 为 `null`，不显示虚假的零出口。

令牌分析的请求总量、额度、模型、耗时等其他指标仍沿用原 NewAPI 日志查询。
这些指标与网络事件数可能存在任务结算等差别，返回的 `network_statistics` 和来源页会说明此区别。

### 登录与注册

认证来源不能使用 API 调用地址回填。BrowserID 关联只用成功且有已确认用户 ID 的认证记录。
同一个 BrowserID 代表同一观测浏览器，不代表硬件身份或必然是同一自然人。
未确认账号的失败尝试作为出口事件展示，不将填写的账号名当成认证成功的身份。

### 时间与分页

IP 查询采用 `[start,end)`。令牌原接口结束秒包含在范围内，跨模块传递时转换为
`start_time=start`、`end_time=end-1`，使窗口对齐。手动修改令牌时间范围会解除固定窗口。

关联表每页 15 项；每个 IP 在主列表中预览少量账号，接口每行的账号／令牌 ID 各限 20 个。
`users`、`tokens` 总数不受预览限额影响，详情支持继续分页读取。`related_ids_truncated`
仅表示关联 ID 预览有省略，不表示事件被抽样。

同一时间范围不等于冻结数据集。调用导入或探针新到达记录可能改变统计。
分页切换可使用 `sync=false` 避免重复触发调用导入，但不承诺数据库快照隔离。

## 检测思路与风控衔接

1. 先看数据质量和来源，确认是否记录了真实出口、探针是否有观测、历史是否完整。
2. 对一人多账号，先用共享出口筛选关联对象，再查看成功认证浏览器的账号关联与时间分布。
   校园、公司、移动 NAT、共享代理可能共用出口，因此共享 IP 只用于提供线索。
3. 对账号异常，查看该账号的认证结果、浏览器变化、登录与注册事件；未认证填写账号的失败尝试单列。
4. 对调用异常，按账号和令牌查看出口数量、失败事件、调用时间、模型，以及令牌是否启用和是否有 IP 限制。
5. 需要处置时打开对应账号的风控卡片，使用既有规则与处置流程。本轮没有新增
   “同 IP 自动封号”或“使用代理自动封号”，没有变更自动处置阈值。

## 接口与实现

| 接口 | 用途 |
| --- | --- |
| `GET /api/ip/stats` | 全量聚合概览 |
| `GET /api/ip/addresses` | 新增，全部有效出口分页 |
| `GET /api/ip/shared` | 多账号共享出口 |
| `GET /api/ip/multi-ip-users` | 多出口账号 |
| `GET /api/ip/multi-ip-tokens` | 多出口令牌 |
| `GET /api/ip/users/:id/ips` | 用户出口列表 |
| `GET /api/ip/details/:ip` | 新增，分源行为画像与关联分页 |
| `GET /api/ip/lookup/:ip` | 轻量网络归属查询 |
| `POST /api/ip/sync` | 调用日志增量同步 |
| `POST /api/ip/attributes` | 已有的管理员属性补录 |

详情支持 `view=users|tokens|events|devices`、`page`、`page_size`，以及来源、窗口、用户、令牌条件。
认证来源没有令牌页签；调用来源没有认证浏览器页签。事件只返回允许字段，
不返回凭证、会话 ID、代理对端地址、未认证填写账号或原始 metadata。

事件明细按 IP、来源、时间、用户或令牌条件下推到数据库查询，并补上 IP／时间和令牌／时间索引。
用户名与令牌名按需批量读取，资料缺失不使事件统计全部失败。

## 剩余限制

- 全站统计按筛选窗口流式读取，避免先复制全部事件；聚合集合仍在内存中，缓存按窗口与数据修订失效，
  不宣称已经实现数据库离线预聚合或生产规模压测。
- 调用导入改为后台批次任务，具有进度、取消、持久游标和中断恢复；单次时间片 15 分钟，未完成部分定时续传。
- 没有接入新的线上 GeoIP／代理查询商；已接入离线 GeoLite2 与 VPN／非住宅／Tor 名单。
  公共代理、住宅代理和单独 ISP 已提供 MMDB 导入入口；没有实际数据库时字段保持未知。
  名单支持定时下载、版本切换和热加载，过期数据不继续作为当前命中证据。
- 已提供属性修正审计、同窗口 IP CSV 导出，以及带预览和原因确认的事件保留清理；默认永久保留。
- 风控 IP 监控保留其最多 200000 条事件的读取边界与提示，不能将其数字直接当成 IP 分析全量统计。
- 长期趋势当前基于实际返回的事件桶，不把没有采集证据的时间段自动补成“零风险”。
- 按当前开发约定不运行完整业务测试；真实数据源、生产数据库迁移和正式探针接入需要单独验收。
